# 参考文本与资料

本目录收录 `story-video-director` 设计、研究和整理过程中参考的相关文本。

## 文件列表

- `ACTING SKILL.md`：AI 视频人物行为、目标、阻力和表演设计参考
- `LIRA SKILL.md`：图片生成与图片编辑提示词优化参考
- `CINEDANCE HIGGSFIELD SKILL.md`：Seedance 2.0 与 Higgsfield 电影提示词参考
- `视频提示词建议.md`：Seedance 分镜、素材引用、声音和中文提示词建议
- `prompt-guide-v1-2.pdf`：提示词指南 PDF，38 页

## 使用说明

- 文件按用户提供的原始名称与内容收录。
- 这些资料用于研究和方法参考，不是安装或运行 `story-video-director` 的必需文件。
- Skill 的实际规则以 `story-video-director/SKILL.md` 及其 `references/` 目录为准。
- 参考资料的署名与权利归原作者或原权利人所有。
- 除非资料自身另有授权声明，本目录内容不包含在仓库根目录的 MIT License 授权范围内。
